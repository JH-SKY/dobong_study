# 학습 요약
uv 패키지 매니저를 활용한 가상환경 구축과 FastAPI 프레임워크의 기초 구조 및 Ruff를 통한 코드 최적화 기법을 습득함.

# 배운 개념 정리
1. uv 패키지 매니저: 기존의 pip보다 훨씬 빠른 속도를 자랑하는 차세대 파이썬 패키지 관리 도구임. 프로젝트 초기화(`uv init`)부터 라이브러리 설치까지 효율적으로 관리할 수 있음.
2. FastAPI: 파이썬 기반의 현대적이고 빠른 웹 프레임워크임. 비동기 프로그래밍을 지원하며, 작성한 코드를 바탕으로 Swagger UI라는 API 문서(사용 설명서)를 자동으로 생성해주는 장점이 있음.
3. Uvicorn: FastAPI로 만든 앱을 실제로 웹에 띄워주는 엔진 역할을 함. "주방(FastAPI)에서 만든 요리를 손님에게 배달하는 서빙 로봇"이라고 생각하면 이해가 쉬움.
4. Ruff: 코드를 실행하기 전에 오타나 잘못된 문법, 사용하지 않는 변수 등을 빛의 속도로 찾아내어 수정해주는 정적 분석 도구임.

@app.get("/")

# 실수/에러와 해결 과정
1. pyproject.toml과 uv.lock의 역할 혼동: 단순히 라이브러리를 적는 곳인 줄 알았으나, 프로젝트의 환경 설정 전체를 정의하고 버전을 고정하는 핵심 파일임을 학습함.
2. Ruff 경고 발생: 사용하지 않는 라이브러리를 import 했을 때 Ruff가 즉시 경고를 띄워줌으로써, 불필요한 리소스 낭비를 막고 코드를 깔끔하게 유지하는 습관을 들임.

# 실무 관점의 참견
실무에서는 협업 시 '환경 통일'이 가장 중요함. uv를 사용하면 팀원들 모두가 동일한 라이브러리 버전을 빠르게 설치할 수 있어 환경 충돌 문제를 방어할 수 있음. 또한 FastAPI의 자동 문서화 기능은 프론트엔드 개발자에게 API 명세서를 따로 써주는 시간을 아껴주어 전체적인 개발 효율을 높여줌.
