## 📅 자바스크립트 핵심 문법 및 데이터 구조 심화 학습 기록

---

### 1. 📝 학습 요약
자바스크립트의 변수 선언 방식, 중첩 조건문의 논리 설계, 함수의 다양한 형태(선언식/화살표), 그리고 대규모 데이터 처리에 효율적인 Map 객체의 실무적 활용법을 마스터함.

### 2. 💡 배운 개념 정리

#### ✅ 변수 선언과 세미콜론 (;)
* **let vs const**: 재할당이 필요한 경우 `let`을, 변하지 않는 값은 `const`를 사용함.
* **세미콜론(;)**: 자바스크립트는 줄바꿈 시 자동으로 세미콜론을 삽입(ASI)하지만, 코드 압축 시 에러 방지와 가독성을 위해 문장 끝에 명시적으로 붙이는 것이 실무 관례임.

#### ✅ 조건문과 논리 연산자
* **중첩 if문**: `if`문 안에 `if`를 넣어 세밀한 조건(예: 나이 확인 후 학생 여부 판단)을 필터링할 수 있음.
* **논리 연산자 (||, &&)**: `||` 사용 시 `(A === '1' || '2')`와 같이 작성하면 뒤의 문자열이 항상 참(Truthy)으로 취급되어 오류가 발생하므로, 반드시 `(A === '1' || A === '2')`와 같이 개별 비교해야 함.

#### ✅ 반복문 (for문)
* **구조**: `for (초기값; 조건식; 증감식)`의 형태.
* **원리**: 조건식이 `true`인 동안 중괄호 `{ }` 안의 코드를 계속 실행함.
* **주의사항**: 
    1. 초기값 변수에도 반드시 `let`을 붙여야 함 (예: `for (let i = 0; ...)`)
    2. 조건식을 잘못 설정하면(예: `a <= b`처럼 고정된 값 비교) 무한 루프에 빠져 프로그램이 멈출 수 있으므로, 변화하는 변수 `i`를 기준으로 조건을 잡아야 함.
    
#### ✅ 함수의 형태와 차이점
* **함수 선언식**: 호이스팅이 적용되어 선언 전 호출 가능.
* **화살표 함수**: `this`가 고정되며 코드가 간결함. `new` 키워드를 사용한 생성자로 사용할 수 없음.

#### ✅ Map 객체 (vs Object)
* **성능**: 데이터의 빈번한 추가/삭제 시 `Object`보다 빠름.
* **자유도**: 키(Key)값으로 문자열뿐만 아니라 숫자, 객체 등 모든 자료형을 사용할 수 있음.
* **순서 보장**: 데이터를 넣은 순서대로 정렬됨.

### 3. 💻 코드리뷰

```javascript
/**
 * 1. 중첩 조건문을 활용한 검정고시 대상 판별
 * 설계 의도: 나이 조건으로 먼저 거른 뒤, 학생 여부를 2차로 확인하여 논리적 계층 형성
 */
let userAge = 18;
let isStudent = false;

if (userAge < 20) {
    if (isStudent) {
        console.log("학생이므로 검정고시 대상이 아닙니다.");
    } else {
        console.log("검정고시 대상입니다."); // 학생이 아니면 대상
    }
} else {
    console.log("성인입니다.");
}

/**
 * 2. 범위 합계 구하기 (반복문과 함수)
 * 설계 의도: 시작(a)부터 끝(b)까지 숫자를 순회하며 누적 합계를 return으로 반환
 */
const sumBetween = (a, b) => {
    let sum = 0; // 누적 합계를 담을 바구니
    for (let i = a; i <= b; i++) { // i가 b가 될 때까지 1씩 증가
        sum += i; 
    }
    return sum; // 결과값 반환
};

/**
 * 3. Map을 활용한 실무적 세션 관리
 * 설계 의도: 숫자형 ID를 키로 사용하여 변환 비용 없이 빠르게 세션 데이터 접근
 */
const sessionMap = new Map();
sessionMap.set(1001, { name: "도봉", history: [] }); // 데이터 저장

if (sessionMap.has(1001)) {
    console.log("접속 중인 유저:", sessionMap.get(1001).name);
}
```

### 4. ❓ 헷갈렸던 점 (Q&A)

**Q. `if (memberLevel === 'platinum' || 'gold')`가 왜 항상 참인가요?**
**A.** 자바스크립트에서 빈 문자열이 아닌 `'gold'`는 항상 `true`로 평가(Truthy)됩니다. 따라서 앞의 비교가 틀려도 `|| true`가 되어 전체 조건이 항상 참이 됩니다. `memberLevel === 'gold'`라고 정확히 써줘야 합니다.

**Q. 함수 안에서 `return` 대신 `console.log`만 쓰면 어떻게 되나요?**
**A.** 함수는 화면에 값을 보여주는 통로가 아니라 결과를 내놓는 기계입니다. `return`이 없으면 함수를 호출한 곳에서 그 값을 받아 다른 계산에 쓸 수 없습니다.

### 5. 🏢 실무 관점 (Insight)

* **구조적 설계**: `Map`은 AI 챗봇의 실시간 세션 관리처럼 데이터가 방대하고 빠르게 변하는 환경에서 `Object`보다 성능과 유지보수 면에서 유리합니다.
* **가공의 미학**: 괄호 색상(Bracket Pair Colorization)이나 `editor.suggestSelection` 설정 등 도구를 활용해 오타를 줄이는 것도 주니어 개발자가 갖춰야 할 중요한 역량입니다.
