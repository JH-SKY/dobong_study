# 📚 학습 기록: 프로그래밍 원리 (Callback & Async)

### 1. 학습 요약
함수를 데이터처럼 다루는 '일급 객체'의 특성을 이해하고, 이를 활용한 콜백 함수, 배열 고차 메서드(forEach), 그리고 비동기 처리의 기초를 학습함.

### 2. 배운 개념 정리
* **콜백 함수 (Callback)**: 내가 직접 실행하지 않고, 특정 조건이 맞을 때 실행해달라고 '제어권'을 넘겨준 함수. (메모지에 적어둔 나중에 할 일)
* **배열 고차 메서드 (forEach)**: 배열의 각 요소를 하나씩 꺼내어 내가 준 콜백 함수에 전달해 주는 '배달원'. 일반 `for`문과 달리 중간에 멈출 수 없지만 코드가 간결함.
* **모듈 (Module)**: 코드를 부품처럼 나누어 관리하는 것. `script src="now_playing.js"`처럼 외부 파일을 불러와 사용하는 구조.
* **비동기 (Asynchronous)**: 빨래를 돌려놓고 설거지를 하는 것처럼, 한 작업(데이터 가져오기)이 끝날 때까지 멈춰 있지 않고 다음 일을 하다가 결과가 나오면 처리하는 방식.

### 3. 코드리뷰 (원리 중심)
```javascript
// [설계 의도] 함수를 인자로 전달하여 반복 업무를 자동화함
const movies = ["아이언맨", "스파이더맨"];

// 1. movies라는 배열에 'forEach'라는 고차 메서드(배달원)를 붙임
// 2. (movie) => { ... } 라는 콜백 함수(메모지)를 인자로 전달함
movies.forEach((movie) => {
  console.log(`${movie} 처리 중...`); // 각 요소마다 이 동작을 반복함
});
```

### 4. 헷갈렸던 점 (Q&A)
* **Q: 일반 for문이랑 forEach 중 뭐가 더 좋은가요?**
    * **A**: 상황에 따라 달라요! 전부 다 확인해야 하면 `forEach`가 가독성이 좋고, 중간에 '철수'를 찾으면 바로 멈춰야(`break`) 한다면 일반 `for`문이 유리합니다.
* **Q: 비동기는 왜 쓰나요?**
    * **A**: 서버에서 데이터를 가져올 때 화면이 굳어버리면 안 되니까요! 데이터를 기다리는 동안에도 사용자가 버튼을 누르거나 화면을 볼 수 있게 해줍니다.

### 5. 실무 관점
* 파이썬과 자바스크립트 모두 함수를 '일급 객체'로 다룹니다. 이 개념을 알면 나중에 AI 모델의 실행 결과를 비동기적으로 화면에 뿌려주는 복잡한 로직도 쉽게 짤 수 있습니다.
